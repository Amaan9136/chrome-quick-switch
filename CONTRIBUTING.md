# Contributing

Thanks for taking an interest in Chrome Quick Switch.

## Before you start

- Check existing issues before opening a new one.
- Keep changes focused. Small pull requests are easier to review.
- Do not include real Chrome profile names, email addresses, or private account data in screenshots, logs, or test fixtures.

## Local development

```bash
npm install
npm start
```

## Pull requests

Please include:
1. A short description of the change.
2. The reason it is useful.
3. The operating system you tested on.
4. Any steps needed to reproduce or verify the change.

If your change affects profile detection or launching, test it with more than one profile where possible.
